# TaskFlow - Project Management App (Assignment 3)

Course: Software for Mobile Devices, Fall 2026, FAST NUCES Lahore
Author: Ali Ahmad (23L-2619)

## Overview
Extends the Assignment 2 TaskFlow app with Fragments, TabLayout and built-in ListViews.
Covers projects, tasks, attachments and discussion, with consistent data passing between screens.

## Screens
- Splash
- Home (project list, search, new project)
- Project: Overview, Tasks, Files, Discussion (tabs)

## Tech
- Android Studio
- Fragments, TabLayout, ListView with custom adapters
- AlertDialog forms, DatePickerDialog, activity result intents
